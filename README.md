# EEG2IMG

NeurIPS 2026 Neural Interface competition, Track 1 (EEG-to-image retrieval).
Final sealed-phase submission: 2-member REVE-base ensemble (63rd of 1,753 submissions).

- configs/datasets: NeuralBench dataset variants used for training
- scripts: slurm wrappers, backup loops, analysis helpers
- patches: library patches kept as diffs only
- submission: solver code and weight converters (no weights)
- env: package lists and config templates
- docs/SESSION_SUMMARY.md: full project timeline

Data is not included (Alljoined-1.6M is licensed non-commercial).
Track 3 (sleep) work lives in track3_sleepnet/.
